# Relatórios — integração e envio para Geterr

A guia **Relatórios** consolida os dados oficiais dos indicadores ABNT e foi desenhada para facilitar o envio periódico à equipe da Geterr.

## Regras

- Descobertas do agente ainda não validadas não são exportadas.
- O relatório usa o valor corrente da base oficial.
- Indicadores parciais podem ser incluídos para mostrar o que já foi localizado e o que ainda falta.
- O CSV usa `;` como separador e UTF-8 com BOM, compatível com Excel em português do Brasil.

## Campos do CSV

- Norma
- Código
- Indicador
- Status
- Numerador
- Ano Numerador
- Fonte Numerador
- URL Numerador
- Denominador
- Ano Denominador
- Fonte Denominador
- URL Denominador
- Valor Final
- Unidade
- Observações

## PDF

O botão **Imprimir / PDF** abre um relatório técnico em orientação paisagem. No navegador, escolha **Salvar como PDF**.
